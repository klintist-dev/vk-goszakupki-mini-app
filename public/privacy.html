Политика конфиденциальности

Дата последнего обновления: 30 апреля 2026 г.

1. Общие положения

Приложение «БюрократЪ» (далее — «Приложение») уважает вашу конфиденциальность и обязуется защищать персональные данные пользователей. Настоящая политика описывает, какие данные собираются, как они используются и хранятся.

2. Какие данные собираются

Приложение получает доступ к следующей информации:

  • ИНН — вводится пользователем для проверки организации или поиска контрактов;
  • Название организации — для поиска по названию;
  • Паспортные данные — для поиска ИНН физического лица;
  • Данные о подписках — сохраняются локально в хранилище VK для уведомлений.

3. Как используются данные

Собранные данные используются исключительно для:

  • Отправки запросов в ФНС России (nalog.ru) и портал госзакупок (zakupki.gov.ru);
  • Отображения результатов поиска в интерфейсе приложения;
  • Отправки уведомлений о новых контрактах (если пользователь оформил подписку).

4. Хранение данных

Приложение не сохраняет данные на собственных серверах. Вся информация:

  • Хранится только на устройстве пользователя (подписки сохраняются в VK Storage);
  • Не передаётся третьим лицам, кроме официальных государственных сервисов (ФНС, Госзакупки);
  • Удаляется при очистке данных приложения или VK Storage.

5. Передача данных третьим лицам

Данные могут передаваться только:

  • На официальные серверы ФНС России (nalog.ru);
  • На официальный портал госзакупок (zakupki.gov.ru).

Иные третьи лица не получают доступ к вашим данным.

6. Ваши права

Вы имеете право:

  • Отказаться от использования приложения в любой момент;
  • Удалить свои подписки через интерфейс приложения;
  • Обратиться к разработчику с запросом об удалении данных.
